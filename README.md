# 과목나침반 (진로·고교과목 선택 도우미)

중학생이 진로를 탐색하고, 희망 고등학교에서 들을 수 있는 과목을 추천받아
2·3학년 과목 계획을 세운 뒤 결과를 이미지로 저장하는 **모바일 우선 웹앱**입니다.

> 📌 현재 **천안 지역 14개 일반계고**의 실제 편제표(학교알리미 2026 공시)와
> 대학 권장과목(대교협 2028 자료집) 기준으로 동작합니다. 다른 지역·학교를 추가하거나
> 자료를 갱신하려면 [`src/data/README.md`](src/data/README.md)를 참고하세요.
> (이전 예시 데이터는 `src/data/_sample_backup/`에 보관돼 있습니다.)

## 실행 방법 (내 컴퓨터에서 보기)

터미널에서 이 폴더로 이동한 뒤:

```bash
npm install
```

```bash
npm run dev
```

그러면 `http://localhost:5173` 주소가 나와요. 브라우저에서 이 주소를 열면 됩니다.
스마트폰처럼 보려면 브라우저 창을 좁게 줄이거나, 개발자도구의 모바일 화면(반응형)으로 보세요.

## 무엇이 들어 있나요

**고교 입학 시뮬레이션** 형태예요. 입학해서 학기마다 진급하며 과목을 골라 졸업장을 받습니다.

| 단계 | 화면 | 설명 |
|---|---|---|
| 1 | 진로 | 진로 결정 여부 → 검색 또는 8문항 탐색 → 진로 후보 |
| 2 | 학교 | 고등학교 선택 (편제표 기준일 표시) |
| 3 | 입학 | ‘OO고등학교에 입학하신 것을 환영합니다’ 오프닝 |
| 4 | 학기 여정 | 1-1 → 3-2까지 6학기. 1학년은 공통과정 안내, 2·3학년은 선택군(택N)에서 과목 선택. 진로 추천은 ⭐, 이미 고른 과목·선수과목 미이수 과목은 비활성+힌트. 화면 하단에 학기마다 우측으로 달려가는 학생 진행바 + 계절 배경 |
| 5 | 졸업 | 6학기 이수 과목·진로 추천·담임 코멘트(규칙 점검 통합)를 담은 **졸업장**을 PNG로 저장 |

> 편제표(학기별 교육과정) 데이터가 있는 학교는 위 시뮬레이션 흐름을 따릅니다. 현재 수록된 천안 14개 고교가 모두 여기에 해당해요.
> 1학년은 전국 공통과정이라 전 학교 공통으로 구성했어요([`src/data/grade1.json`](src/data/grade1.json)).
> 편제표가 아직 없는 학교를 넣으면 대체 경로(추천 → 드래그식 배치)로 자동 전환됩니다.

- 로그인 없음 · 서버 없음 · AI 없음 (모두 브라우저 안에서 동작)
- 진행 상황은 브라우저에 자동 저장되고, ‘처음부터’ 버튼으로 초기화됩니다.
- 같은 과목은 여러 학기에 중복 배치되지 않아요(이미 고른 학기가 칩에 표시됨).

## 폴더 구조

```
src/
  data/        ← 앱의 모든 내용(JSON). 실제 데이터로 교체하는 곳
  lib/         ← 추천 점수·규칙 점검 등 계산 로직 (AI 아님)
  screens/     ← 화면 9개
  ui.tsx       ← 공통 UI(헤더·진행바·버튼·배지)
  context.tsx  ← 진행 상태 저장/복구
```

## 다음 단계 (실제 데이터 넣기)

1. 대상 학교의 최신 교육과정 편제표를 확보합니다.
2. 대학·학과별 공식 권장 과목 자료를 모읍니다.
3. 엑셀/CSV로 정리한 뒤, "이 자료를 데이터 파일로 바꿔줘"라고 요청하면
   `src/data/*.json` 형식으로 변환해 드립니다.
